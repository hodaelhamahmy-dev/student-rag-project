# 📚 Student RAG Assistant

A Retrieval-Augmented Generation (RAG) application built with **Python**, **ChromaDB**, **Sentence Transformers**, **OpenRouter**, and **Streamlit**.

The application allows users to ask questions about PDF documents and receive accurate answers generated by an LLM using only the retrieved document context.

---

## 🚀 Features

- 📄 Load PDF documents
- 🧹 Text preprocessing
- ✂️ Text chunking
- 🧠 Sentence embeddings using Sentence Transformers
- 🗄️ Vector database with ChromaDB
- 🔍 Semantic similarity search
- 🤖 Answer generation using OpenRouter LLM
- 🌐 Interactive Streamlit web interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/hodaelhamahmy-dev/student-rag-project.git

cd student-rag-project
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the project root.

```env
OPENROUTER_API_KEY=your_api_key
OPENROUTER_MODEL=openai/gpt-4o-mini
```

---

## ▶️ Run the Application

```bash
streamlit run streamlit_app.py
```

Then open:

```
http://localhost:8501
```
